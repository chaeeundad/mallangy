# 말랑말랑 친구들 · 무지개를 찾아서

아이들이 만든 말랑이 작업실에서 시작한 작은 모험 게임입니다. 직접 만든 친구와 세 개의 세계를 여행하며 흩어진 무지개를 되찾습니다.

## 실행

Node.js 22.12 이상을 사용합니다.

```sh
npm ci
npm run dev
```

브라우저에서 터미널에 표시된 주소를 엽니다. 기존처럼 HTML 파일을 직접 여는 대신 개발 서버를 사용합니다. 배포용 파일은 `npm run build`로 생성하는 `dist/`입니다. `npm run preview`로 배포본을 열 수 있습니다.

## 게임

- **작업실**: 10가지 모양, 16가지 색, 표정, 색칠, 스티커, 속 재료와 말랑한 3D 촉감. 최근 40단계의 꾸미기 작업을 되돌릴 수 있습니다.
- **무지개 여행**: 햇살 초원, 딸기빛 숲, 별빛 구름섬의 9개 코스와 지역 친구들의 이야기.
- **조작**: ← → / A D 이동, Space / ↑ / W 점프, Esc 일시정지. 점프 버튼을 길게 누르면 높게 뜁니다. 발판을 막 벗어난 순간의 점프와 착지 직전의 점프 입력에도 여유를 줍니다.
- **안전한 모험**: 낙하하면 안전 깃발에서 다시 시작하며 이미 주운 수집품은 유지합니다. 별을 모두 모으지 않아도 도착하면 다음 이야기가 열립니다.
- **수첩**: 친구 20명까지 저장, 코스별 최고 수집 기록과 최단 시간, 기념 배지.
- **쉬어가기**: 다른 창으로 이동하거나 화면을 잠그면 게임을 멈춥니다. 코스를 떠나면 진행 중인 코스는 초기화되며 완료한 기록은 유지합니다.

## 말랑이 이야기

메뉴의 **말랑이 이야기**에서 《말랑이와 작은 빛의 씨앗》을 32쪽으로 읽습니다. 기다림의 정원, 나눔의 소풍, 약속의 별자리를 지나 비와 바람 속에서 서로에게 도움을 청하는 이야기입니다. 그림의 꽃·구름·딸기·별·빗방울·무지개를 눌러 장면을 변화시킬 수 있습니다. 그림 놀이를 완료하지 않아도 자유롭게 페이지를 넘길 수 있습니다.

이전·다음 버튼, 좌우 방향키, 가로 쓸어 넘기기, 목차, 큰 글자 보기, 자동 책갈피와 완독 기록을 지원합니다. 작업실의 이름·색·모양·얼굴 조절·무늬·붓 자국·장식을 이야기의 주인공에 반영합니다. 삽화는 외부 서비스에 의존하지 않는 SVG입니다. 여덟 장소의 장면 구성에 페이지별 소품·날씨·행동을 더해 이야기를 따라갑니다.

## 캐릭터 스튜디오

몸·얼굴·장식·촉감·저장 분류를 PC와 모바일에서 동일하게 제공합니다.

- 네 가지 시작 스타일, 깜짝 스타일, 자유 색상, 도트·줄무늬·그라데이션, 표면 광택.
- 얼굴 위치와 크기, 눈 간격과 색, 볼터치 진하기.
- 붓 색·크기·진하기, 붓 자국만 지우기.
- 24가지 장식, 붙인 장식 목록, 선택·끌어 옮기기·크기·회전·개별 삭제.
- 40단계 되돌리기와 다시 적용, 정면 보기, 투명 배경 PNG 저장.

얼굴을 고정된 깊이에 놓던 방식 대신 실제 몸의 앞쪽 삼각형에 연결합니다. 얼굴의 폭에 해당하는 여러 표면 위치를 확인하고, 몸이 눌릴 때도 연결한 삼각형의 변형을 따라 깊이를 갱신합니다. 졸린 표정에서도 얼굴 전체를 몸 안쪽으로 축소하지 않습니다. 별이는 정면에서 다섯 꼭짓점이 보이는 형태로 정비했습니다.

분류에서 스타일을 고르고 위치·크기를 조절하는 흐름은 [Nintendo의 Mii 안내](https://en-americas-support.nintendo.com/app/answers/detail/a_id/22378/c/183)와 [공식 Mii 채널 설명서](https://csassets.nintendo.com/noaext/image/private/t_KA_PDF/WiiRVKChEng?_a=DATAg1AAZAA0)의 조작 패턴을 참고했습니다. 게임의 그래픽 자산은 사용하지 않습니다.

## 모바일 전용 UI

모바일에서는 PC 메뉴 대신 안전 영역을 반영한 하단 탭을 사용합니다. 홈의 세계 카드는 가로로 넘길 수 있습니다.

작업실은 말랑이 미리보기와 도구 트레이로 나뉩니다. 몸·얼굴·장식·촉감·저장 탭과 빠른 촉감 도구를 제공하며, 이름 입력 때는 가상 키보드가 차지하는 공간에 맞춰 트레이를 조절합니다.

모험 중에는 메뉴를 숨기고 게임 전용 화면을 씁니다. 세로에서는 엄지 조작 패드를 분리하고, 가로에서는 버튼을 게임 화면 양쪽에 배치합니다. 모바일 브라우저의 홈 화면 추가 기능을 위한 앱 매니페스트를 포함합니다. 오프라인 실행을 위한 서비스 워커는 포함하지 않습니다.

## 저장

친구·여행·설정은 이 브라우저의 로컬 저장소에 자동 기록합니다. 로그인이나 서버로의 개인정보 전송은 없습니다. 이전 프로토타입의 `malang-draft`, `malang-gallery` 기록도 처음 실행할 때 읽습니다. 동일 도메인·브라우저일 때 이전 기록을 가져올 수 있습니다. Vercel 미리보기와 운영 도메인은 저장 공간이 서로 다릅니다.

기기를 바꾸거나 브라우저 데이터를 지우기 전 **설정 → 파일로 보관**을 사용하세요. JSON 파일을 불러올 때는 확인 창에서 현재 기록을 먼저 보관할 수 있습니다. 코스 도중의 위치는 저장하지 않습니다.

## 개발 구조

- `src/data.ts`: 이야기, 지역, 코스, 캐릭터 데이터
- `src/game/physics.ts`: 고정 시간 간격 이동, 발판 충돌, 점프 입력 여유
- `src/game/engine.ts`: 입력, 수집, 체크포인트, 게임 수명 주기
- `src/game/draw.ts`: 외부 이미지 없이 그리는 세계와 캐릭터
- `src/workshop/`: 아이들이 만든 Three.js 작업실을 분리하고 정비한 모듈
- `src/storage.ts`: 이전 기록 이전, 형식 검사, 버전별 저장, 백업
- `src/mobile.css`: 모바일 전용 메뉴, 작업실, 게임 조작 화면

글꼴과 Three.js는 설치 시 받은 패키지를 배포 파일에 포함합니다. 실행 중 CDN이나 외부 글꼴 서버에 의존하지 않습니다. 작업실은 처음 열 때 별도로 불러옵니다.

## 확인 명령

```sh
npm run build
npm test
npx playwright install chromium
npm run test:e2e
```

자동 단위 확인은 저장 데이터와 점프·충돌을 다루고, 브라우저 시나리오는 PC·모바일 메뉴, 꾸미기, 저장, 게임과 일시정지를 다룹니다. 실제 조작감과 기기별 화면은 플레이하며 확인해야 합니다.

## Vercel

루트 디렉터리는 이 저장소입니다. `vercel.json`에 Vite, `npm run build`, 출력 디렉터리 `dist`를 지정했습니다. 기존 프로젝트에 수동으로 덮어쓴 Build Command나 Output Directory가 있다면 이 값과 맞춰야 합니다. 환경 변수는 필요하지 않습니다.

## 원작과 재료

아이들이 만든 최초의 말랑이 작업실과 캐릭터 콘셉트를 이어갑니다. 참고 음원 `assets/slime-squish.mp3`은 배포본에서 재생하지 않습니다. 원출처와 CC0 표기는 `assets/README.txt`에 있습니다. 효과음은 Web Audio로 합성합니다. 패키지의 글꼴·라이브러리 라이선스는 각각의 패키지에 포함되어 있습니다.

## AR 별빛 모험

게임 홈의 **별빛 모험** 또는 같은 주소의 `/ar/`를 여세요. 같은 브라우저에서 작업실에 만든 현재 말랑이 또는 저장한 친구를 선택할 수 있어요. 패턴·표정·몸 색·광택·모양이 반영되며, 붓 자국·스티커·속 재료는 이 버전의 AR에 표시하지 않습니다. 친구 폰에 보내는 정보는 색과 모양 등의 외형, 마커 기준 좌표와 별 상태뿐입니다. 이름, 카메라 화면, GPS는 전송하지 않습니다.

한 명이 만든 **가족 링크**를 각자 Safari에서 열고, 같은 인쇄 카드를 비추면 코드 입력 없이 한 방에 들어갑니다. 섬의 바위나 풀숲 근처를 눌러 걸어가면 숨은 별이 나타납니다. 8개를 함께 모으면 완료입니다. 가족 링크를 가진 사람만 그 가족의 방을 찾을 수 있으니 공개하지 마세요. 링크 없이 연습 모드는 혼자 플레이할 수 있습니다.

### Vercel + Cloudflare

- 기존 GitHub 연결 Vercel 프로젝트가 두 페이지를 같이 빌드합니다. `/ar/`에서만 카메라가 허용되고 기존 게임의 카메라 차단 정책은 유지됩니다.
- Cloudflare에서 별도 D1과 Worker를 만들고 `backend/wrangler.example.jsonc`를 참고해 실제 D1 ID와 Vercel **프로덕션 origin**을 `ALLOWED_ORIGIN`에 넣습니다. DB 스키마를 적용한 뒤 Worker를 배포합니다.
- Vercel 프로덕션 환경 변수 `MALLANG_AR_BACKEND_URL`에 HTTPS Worker origin을 설정하고 다시 배포합니다. 이 값이 비어 있으면 협동 방 API만 작동하지 않으며 혼자 연습은 가능합니다. 브라우저는 Vercel의 같은 도메인으로만 요청합니다. 계정별 Cloudflare 설정과 비밀 값은 Git에 올리지 마세요.
- 확인: iPhone 두 대가 같은 가족 링크와 카드로 입장하는지, 서로 다른 작업실 외형을 표시하는지, 클릭해 같은 별을 한 번만 모으는지 확인합니다. 그리고 다른 가족 링크에서는 같은 카드라도 방이 분리되는지 확인합니다.
