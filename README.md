# 말랑말랑 친구들

아이들과 함께 말랑이를 꾸미고, 만든 친구로 횡스크롤 모험을 즐기는 웹 프로토타입입니다.

## 실행 방법

`index.html`을 최신 브라우저에서 열어 주세요. Three.js와 글꼴을 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 조작 방법

- 키보드: ← / → 또는 A / D로 이동, Space / ↑로 점프
- 터치 화면: 좌우 버튼과 점프 버튼
- 말랑이 작업실에서 현재 만들던 친구 또는 저장한 친구를 골라 모험을 시작할 수 있습니다.

가족과 함께 수정하려면 GitHub 저장소의 Settings → Collaborators에서 가족의 GitHub 계정을 초대하면 됩니다.
